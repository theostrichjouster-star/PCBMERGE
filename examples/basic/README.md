# The example designs

Two boards, one drawn in each tool, so the merge can be tried against real
hardware rather than something written to suit it.

| Design | Tool | Published by |
| --- | --- | --- |
| Adafruit INA3221 Breakout | EAGLE | [Adafruit Industries](https://github.com/adafruit/Adafruit-INA3221-Breakout-PCB) |
| SparkFun Thing Plus ESP32-S3 | KiCad | [SparkFun Electronics](https://github.com/sparkfun/SparkFun_Thing_Plus_ESP32-S3) |

**These are not ours and the project's MIT licence does not cover them.** Both
vendors publish their hardware as open source, Adafruit under CC BY-SA and
SparkFun under CC BY-SA 4.0 at the time of writing. Check the terms in the
repositories above before reusing either design. Anything the tool writes out of
them carries their terms with it, not this project's.

Swap them for your own designs whenever you like. Nothing in the code or the
tests names a design, a library or a net.
